**Table** — трекер привычек в виде таблицы «привычка × день месяца». Каждый день отмечается выполнение, приложение считает процент, серии и итог месяца и хранит архив по месяцам. Работает в браузере и как PWA без сети, синхронизирует данные между устройствами через вход Google. Бланк месяца можно распечатать, заполнить от руки и перенести отметки в приложение по фото.

Стек: Vue 3, Vite, Pinia, Tailwind CSS 4, vue-i18n, Firebase (Auth и Firestore), vite-plugin-pwa.

## Возможности

### Отметки

- У клетки три состояния: выполнено, не выполнено (пусто) и пропуск. День с пропуском не учитывается в проценте.
- Отмечать можно прошедшие дни и сегодняшний. Будущие месяцы не открываются.
- Компьютер: таблица месяца. Клик по клетке ставит «выполнено», второй клик или правый клик — пропуск, третий клик стирает отметку. Клик по числу в шапке отмечает день у всех привычек, правый клик по числу ставит пропуск. Alt+клик открывает заметку к дню.
- Телефон (экран уже 768 px): лента дней и отметки за выбранный день. Тап по кружку переключает выполнено → пропуск → пусто, долгое нажатие ставит пропуск. Свайп по списку меняет день, свайп по названию месяца — месяц. Быстрые действия: перейти к сегодняшнему дню, ко вчерашнему или к неотмеченным дням, отметить всё за день, снять выполненные.

### Привычки

- До 20 привычек в месяце и до 8 отметок в день у каждой (например, подходы или стаканы воды).
- Название до 60 символов, эмодзи (поиск по каталогу и подсказки по названию привычки), один из 8 цветов.
- Расписание: каждый день, по выбранным дням недели или N раз в неделю (до 6). Дни вне расписания помечаются пропуском. Когда цель недели набрана, оставшиеся пустые дни этой недели помечаются пропуском. У неполных недель на краях месяца цель пропорционально меньше.
- Пауза: привычка не входит в средний процент, отмечать её можно как обычно.
- Заметки к дням, до 500 символов.
- Порядок меняется перетаскиванием или кнопками «Выше» и «Ниже».
- Карточка привычки: отметки за месяц, текущая и лучшая серия, среднее за все месяцы и по каждому месяцу.

### Прогресс и статистика

- Процент выполнения по каждой привычке и средний процент за месяц. Расчёт ведётся от всех дней месяца или только от прошедших.
- Итог месяца рядом со средним процентом: только процент, звёзды 0–5, буквы A–F, оценка 2–5 или ничего. По умолчанию для русского языка показывается оценка 2–5, для остальных — процент.
- Серии считаются в днях, у привычек с целью «N раз в неделю» — в неделях.
- Окно статистики по годам: среднее за год, число выполненных отметок, лучшая серия, тепловые карты месяца и года, среднее по месяцам, таблица привычек за год.

### Месяцы и архив

- Каждый месяц хранится отдельно. Прошлые месяцы открываются стрелками, отметки в них можно исправлять, статистика пересчитывается.
- Новый месяц при первом открытии получает привычки последнего заполненного месяца с чистыми отметками.
- Из архивного месяца привычки переносятся в текущий вручную: выбираются нужные привычки, их можно добавить к текущим или заменить текущие.
- Поиск: фильтр привычек открытого месяца и поиск по названиям, эмодзи и заметкам во всех месяцах.

### Отмена и повтор

- Отменяются и возвращаются последние 50 изменений: отметки, правки и порядок привычек, удаление, перенос, импорт, заметки, пауза, загрузка из облака.
- История отмены хранится до перезагрузки страницы.

### Бланк и фото

- Печать бланка месяца формата A4 с угловыми маркерами ArUco и QR-кодом.
- Фото заполненного бланка распознаётся в браузере. На экране проверки отличия от текущих данных обведены сплошной рамкой, сомнительные отметки — пунктирной, нажатие меняет отметку. После проверки отметки переносятся в таблицу.
- Бланк привязан к месяцу и привычкам, для которых он распечатан. О бланке другого месяца и о привычках, удалённых после печати, приложение предупреждает.

### Данные

- Данные хранятся в браузере (`localStorage`), приложение работает без сети.
- Экспорт и импорт JSON (файл до 2 МБ). Перед импортом показывается сводка и выбор: объединить с текущими данными (для месяцев, которые есть и здесь, и в файле, выбирается версия) или заменить всё вместе с настройками.
- Перед импортом сохраняется резервная копия текущих данных. Её можно восстановить или скачать, сам импорт можно отменить.
- Экспорт CSV открытого месяца или всех месяцев.

### Синхронизация

- Вход через Google, данные хранятся в Firestore по месяцам.
- Без сети изменения копятся на устройстве и отправляются, когда появляется соединение. Состояние синхронизации видно в интерфейсе.
- Если месяц на устройстве и в облаке различается, версия выбирается для каждого месяца. Выбор можно отложить, остальные месяцы при этом синхронизируются.
- При выходе локальные данные удаляются с устройства. Если изменения не дошли до облака, приложение предупреждает и предлагает сохранить их в файл.

### Настройки и интерфейс

- Тема: светлая, тёмная или системная.
- Начало недели: понедельник, воскресенье или по языку и региону. Разделители недель в таблице включаются отдельно.
- Таблица и переключатели управляются с клавиатуры, у клеток есть подписи для экранных чтецов.
- PWA: установка на устройство, работа без сети, сообщение о новой версии с кнопкой обновления.
- Приветственное окно с объяснением отметок, повторно открывается из настроек («Как пользоваться»).

## Быстрый старт

Нужны Node.js и pnpm.

```sh
git clone https://github.com/korgmen/table-habit-tracker.git
cd table-habit-tracker
pnpm install
pnpm dev
```

Команды:

- `pnpm dev` — dev-сервер Vite.
- `pnpm build` — сборка в `dist/`.
- `pnpm preview` — локальный просмотр сборки.
- `pnpm lint` — проверка ESLint, `pnpm lint:fix` — с исправлением.
- `pnpm format` — форматирование Prettier.
- `pnpm test` — тесты Vitest, `npx vitest run` — один прогон.

Service Worker и установка PWA работают в сборке: `pnpm build`, затем `pnpm preview`.

## Структура проекта

- `src/App.vue` — корневой компонент: таблица на компьютере или лента дней на телефоне, глобальные горячие клавиши, печать бланка, окна и тост.
- `src/main.js` — запуск Vue, Pinia, vue-i18n и авторизации.
- `src/i18n.js` — настройка vue-i18n, выбор языка и правила множественного числа.
- `src/stores/habitStore.js` — состояние и логика: привычки, отметки, прогресс, месяцы, настройки, отмена, импорт и экспорт, вход и синхронизация.
- `src/stores/modalStore.js` — стек окон, очередь окон, которые приложение открывает само, и тост.
- `src/utils/` — чистые функции: `archive.js` (архив, проверка и починка данных, перенос привычек), `habitMath.js` (прогресс, серии, расписание и цели), `stats.js` (статистика), `cloudSync.js` (решения синхронизации по месяцам), `csv.js` (CSV), `emojiSearch.js` (поиск эмодзи), `sheetLayout.js` (геометрия бланка и содержимое QR), `sheetScan.js` (распознавание фото бланка).
- `src/composables/` — `useHabitUtils.js` (дни месяца, тема, недели), `useModals.js` (сценарии окон и закрытие кнопкой «назад»), `useGridNavigation.js` (клавиатура в таблице), `useGestures.js` (свайпы и долгое нажатие), `useSearch.js` (поиск).
- `src/directives/radioGroup.js` — клавиатура в группах переключателей.
- `src/components/` — интерфейс: таблица (`HabitGrid`, `HabitRow`, `MarkCircle`), телефон (`MobileView`), окна (`HabitSheet`, `SettingsSheet`, `StatsSheet`, `ImportSheet`, `ConflictSheet`, `NoteSheet`, `SearchSheet` и другие), бланк и фото (`PaperSheet`, `PhotoImport`).
- `src/locales/` — словари интерфейса.
- `src/firebase.js` — публичная web-конфигурация Firebase.
- `firestore.rules` — правила Firestore: пользователь читает и пишет только свои документы.
- Конфиги: `vite.config.js` (Vite, PWA, Tailwind, Vitest, данные эмодзи), `eslint.config.js`, `.prettierrc`.
- Тесты `*.test.js` лежат рядом с модулями.

## Архитектура и данные

- Архив: `localStorage.habitArchive` = `{ "YYYY-MM": { tasks: [...] } }`. Настройки хранятся отдельными ключами (`theme`, `lang`, `weekStart`, `showWeekSeparators`, `calculationMode`, `summaryStyle`), резервная копия перед импортом — в `habitArchiveBackup`, метаданные синхронизации — в `habitSyncMeta`.
- Привычка: `{ id, title, progress, subtasks: [{ id, marks }], color?, emoji?, schedule?, goal?, paused?, notes? }`. В `marks` по элементу на каждый день месяца: `true` — выполнено, `null` — не выполнено, `false` — пропуск.
- Firestore: `users/{uid}` содержит настройки и служебные поля, месяцы лежат в `users/{uid}/months/{YYYY-MM}`. Локальный кэш Firestore хранится в IndexedDB.
- Окна: стек в `modalStore`, окна рендерит `ModalEntry.vue`, кнопка «назад» закрывает верхнее окно.
- Раскладка бланка в `src/utils/sheetLayout.js` общая для печати и распознавания. `js-aruco2` и `jsqr` подгружаются при первом распознавании.
